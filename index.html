개인용 프로젝트

Sharelink Personal Tool

토스쇼핑 쉐어링크 상품 정보를 활용하여 개인 SNS 및 콘텐츠 채널에 게시할 상품 소개 콘텐츠를 제작하기 위한 개인용 개발 프로젝트입니다.

프로젝트 목적

토스쇼핑 Open API를 통해 상품 정보를 조회한 뒤 해당 정보를 기반으로 SNS 게시글, 상품 소개 문구, 숏폼 콘텐츠 초안 등을 작성하는 데 활용합니다.

주요 기능

  • 토스쇼핑 상품 정보를 활용한 콘텐츠 작성
  • SNS 및 블로그용 상품 소개 문구 생성
  • 숏폼 영상용 대본 및 자막 초안 생성
  • 채널별 게시 콘텐츠 작성 보조
  • 게시 콘텐츠 및 게시 이력 관리

이용 범위

본 프로젝트는 외부 사용자에게 상품을 검색하거나 카테고리별로 전시하는 쇼핑몰 형태의 서비스가 아닙니다.

Open API를 통해 제공받은 상품·가격 정보를 별도의 상품 데이터베이스로 축적하거나 상품 검색·가격 비교·상품 전시 목적으로 사용하지 않습니다.

API로 조회한 상품 정보는 콘텐츠 제작에 활용하며, 개인적인 SNS 및 콘텐츠 게시 자동화 목적으로 사용할 예정입니다.

안내

현재 개발 초기 단계이며, 토스쇼핑 Open API 이용 정책과 관련 가이드를 준수하여 사용할 예정입니다.
